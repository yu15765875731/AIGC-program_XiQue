# 企业知识库智能问答平台 — 项目概述

> 本文档是项目的 **30 秒电梯演讲 + 一页纸总览**，面试时用这个框架讲项目。

---

## 1. 一句话定位

**面向中小企业的 AI 知识库智能问答 SaaS 平台**，帮助企业把内部文档（制度、手册、FAQ、代码）变成可被自然语言查询的"企业大脑"，员工问一句话就能得到精准答案，而不用翻文件夹。

---

## 2. 要解决的问题（痛点）

| 角色 | 痛点 | 量化影响 |
|------|------|----------|
| 新员工 | 入职要翻 50+ 份文档才能找到一个流程 | 平均 2 周才能独立上手 |
| 客服 | 1000+ 条 FAQ 记不住，重复回答相同问题 | 人均日处理量 40-60 条，出错率 15% |
| 管理层 | 决策需要的信息散落在各部门 | 信息获取耗时 2-3 小时/次决策 |

---

## 3. 目标用户

**主要客户：20-500 人规模的中小企业（SME）**，三类决策人：

| 决策角色 | 核心诉求 | 付费意愿 |
|----------|----------|----------|
| CEO / 老板 | 降本提效，数据可沉淀 | 高（直接 ROI 驱动） |
| IT 负责人 | 部署简单、安全可控、不添运维负担 | 中（怕麻烦） |
| 业务负责人（客服/HR/运营） | 真能用、答案准、改了能生效 | 高（一线痛） |

**成本结构（核心是 LLM token 成本）：**
- 云端 LLM API 调用成本（GPT-4o-mini / DeepSeek）：约占收入 15-25%
- 向量数据库存储 + 带宽：约 8%
- 服务器 + 运维：约 12%
- 毛利率目标：> 50%

## 5. 竞品简析

| 竞品 | 类型 | 优势 | 劣势 | 我们的机会 |
|------|------|------|------|------------|
| 百度文心一言 + 知识库 | 大厂平台 | 品牌强、生态全 | 价格高、定制化差、SME 无感 | 轻量、价格友好、垂直场景深 |
| Dify / FastGPT | 开源框架 | 免费、可控 | 要自己搭、运维重 | SaaS 化、零运维、开箱即用 |
| 飞书/钉钉 内建 AI | IM 插件 | 用户已在 IM 里 | 只在 IM 生效、跨平台不行 | 独立 Web + API + 多端覆盖 |
| 自建 RAG | 传统做法 | 完全可控 | 开发周期 2-3 月、迭代慢 | 5 分钟上线、按需扩展 |

---

## 6. 核心差异化（3 个就够，面试能讲清）

1. **5 分钟上线 + 零运维**：上传文件夹 → 自动向量化 → 直接问答，不需要配置服务器
2. **答案可溯源 + 主动纠错**：每条回答都带文档来源链接，用户点"不对"直接反馈，系统自动修正检索参数
3. **Agent 工作流模板市场**：内置 20+ 行业模板（客服应答链、入职引导、合同审查），拖拽即用

---

## 7. 项目阶段与里程碑

| 阶段 | 时间 | 目标 | 关键产出 |
|------|------|------|----------|
| P0 - MVP | 月 1-2 | 跑通"上传→向量化→问答"主链路 | 知识库管理 + 智能问答 两个核心模块 |
| P1 - 闭环 | 月 3-4 | 答案可溯源 + 用户反馈闭环 + 多租户 | PRD 全量交付 + 技术架构落地 |
| P2 - 商业化 | 月 5-6 | 计费 + 模板市场 + API 开放 | 可对外销售 |

---

## 8. 成功指标（北极星 + 关键指标）

- **北极星指标**：周活跃问答用户数（WAU）
- **AARR 指标**：
  - Acquisition：官网注册转化率 > 15%
  - Activation：注册 7 天内完成首次问答 > 60%
  - Retention：30 天留存 > 40%
  - Revenue：付费转化率 > 5%
  - Referral：NPS > 40
- **产品指标**：问答满意度（👍 比例）> 80%、平均响应时间 < 3s
